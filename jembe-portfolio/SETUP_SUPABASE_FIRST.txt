JEMBE — SIMPLE SUPABASE SETUP

1. Open your Supabase project.
2. Open SQL Editor → New query.
3. Open SUPABASE_ONE_SQL.sql from this folder and paste ALL of it into the SQL Editor.
4. Click Run.
5. Go to Authentication → Users → Add user.
6. Create: jembevalentin@gmail.com
7. Choose your password.
8. Open the creator-universe folder.
9. Copy .env.example to .env.
10. Put your Supabase URL and public publishable/anon key in .env.
11. In the creator-universe folder run:

   npm install
   npm run dev

12. Open http://localhost:5173/admin
13. Sign in with jembevalentin@gmail.com and the password you created.

Do NOT put a Supabase service-role key in the frontend.
